# The exact core toolchain every gate runs against, locally and in CI.
#
# Bump these deliberately. Nothing resolves them for you, so a Home Assistant
# release never changes a build on its own.
#
# The two lines move together. pytest-homeassistant is core's own test
# package, released under the same version as core, and each release pins
# that exact core release, so a mismatched pair cannot install.
#
# The test package cannot be left unpinned, because the resolver would pick a
# release of its own, which can pin a different core release or none at all.
#
# ampio-mqtt is deliberately absent. It is pinned in
# custom_components/ampio/manifest.json, which is what the Marketplace and
# Home Assistant core install, and the gates read it from there so the tested
# version is always the shipped version.
#
# mypy and pyright are pinned here because the type gates run from this venv,
# locally and in CI. pyright carries the nodejs extra, so the venv installs a
# Node.js runtime with it and the gate never downloads one on its first run.
# ruff is not pinned here, because its pre-commit hook pins the version itself.
